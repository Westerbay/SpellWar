SpellWar

SpellWar is a third-person 3D game developed in C++ with OpenGL, featuring a custom-built game engine and real-time gameplay mechanics. The GitHub contains both the game logic and the engine built from scratch.

In SpellWar, players control characters across floating platforms. It is still in development and the game will emphasize mobility, precision jumping, and character selection.

Versions

MVP 1.0

✅ Features :

  • Floating platforms
  • Multiple playable characters
  • Third-person movement
  • Platform-jumping mechanic
